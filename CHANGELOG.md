# Changelog

## v1.1.0 (Unreleased)
### Balance
- Reduced boss normal punch range.
- Slightly increased boss punch interval.
- Rebalanced boss pacing to improve fairness.

### Gameplay
- Increased player arrow momentum and travel feel.
- Improved reliability of ice + bounce pad combo interaction.
- Added stronger horizontal momentum on successful ice+bounce combo.

### Enemies
- Bomb goblin explosion delay reduced for faster detonation.
- Shooting slime behavior cleaned up and validated.

### Bug Fixes
- Fixed pushable block drop collision-state error caused by physics query timing.
- Fixed stale boss attack helper call references.
- Multiple boss collision/hit-detection stability improvements.
